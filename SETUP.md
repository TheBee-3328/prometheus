# AI setup agent — unattended Cursor environment

Goal: bring a machine from clone → reconstructing data → Nix shell → auto-approve agent loop with **no human clicks**.

## 0. Preconditions

- NixOS or Nix installed (`nix --version`)  
- `git`, `gh` authenticated to push if needed  
- ≥ 12 GB RAM recommended; ≥ 20 GB free disk for parts + `target/` + judge_work  
- This repo: `git clone https://github.com/TheBee-3328/prometheus.git && cd prometheus`

## 1. Data (cannot push 1 GB wholes to GitHub)

Wholes `enwik8` / `enwik9` are **gitignored**. Parts are committed:

| Artifact | Parts | Bytes each |
|---|---|---|
| enwik8 | `data/enwik8.parts/enwik8.part_00`–`01` (2) | 50 000 000 |
| enwik9 | `data/enwik9.parts/enwik9.part_00`–`19` (20) | 50 000 000 |

```bash
chmod +x scripts/reconstruct_data.sh
./scripts/reconstruct_data.sh both
# expects SHA256OK + sizes 1e8 and 1e9
ls -lh enwik8 enwik9
```

**Alternate:** download official enwik9, then `head -c 100000000 enwik9 > enwik8`.

## 2. Nix toolchain

```bash
nix develop -c rustc --version
nix develop -c ./judge_selftest.sh
nix develop -c ./judge.sh enwik8 .
```

Flake may pull **fenix nightly** for `-Z build-std` (tiny decompressor). First enter can take several minutes.

If `NIX_LDFLAGS` breaks on paths with spaces, judge/flake already clear it — keep that.

## 3. Cursor CLI — auto-approve (“Run Everything”)

Config file: `~/.cursor/cli-config.json` (see skill `update-cli-config`).

For unattended runs set:

```json
{
  "approvalMode": "unrestricted",
  "sandbox": { "mode": "disabled", "networkAccess": "allow_all" },
  "permissions": {
    "allow": ["Shell(**)", "Write(**)", "Read(**)", "WebFetch(**)", "WebSearch(**)", "Mcp(**)"],
    "deny": []
  }
}
```

Notes:

- `"unrestricted"` ≈ Run Everything / `--force` / `--yolo`  
- Prefer allowlisting `Shell(**)` + git/nix/cargo if unrestricted is too wide for the host  
- Project overlay: `.cursor/cli.json` merges on top for this repo only  

Also enable in Cursor UI if present: **Auto-run / Run Everything** for Agent mode.

## 4. Start the orchestrator (long loop)

Give the agent `HANDOFF.md` + this file + user master prompt (Phase orchestration). Critical addenda:

```text
Nix only: nix develop -c …
Watchdog: prompts/AGENT_WATCHDOG.md (cannot Task.resume mid-flight)
Unstick: prompts/ORCHESTRATOR_UNSTICK.md
Never commit enwik8/enwik9 wholes; parts live under data/
Stay live: poll agents; soft/hard timeouts; merge only on judge PASS
Push main after every accepted merge + LOG/STATUS update
```

Optional CLI:

```bash
# example — adjust to your Cursor CLI entrypoint
agent --yolo  # or cursor agent with approvalMode unrestricted
```

## 5. Smoke checklist (setup agent must PASS)

- [ ] `git status` clean or understood  
- [ ] `./scripts/reconstruct_data.sh both`  
- [ ] `nix develop -c ./judge_selftest.sh` → PASS  
- [ ] `nix develop -c ./judge.sh enwik8 .` → `ROUNDTRIP=OK` and SCORE ≤ **28080343** (or record new best)  
- [ ] `nix develop -c ./tests/adversarial_roundtrip.sh` → 10/10  
- [ ] `approvalMode` unrestricted (or documented allowlist)  
- [ ] Disk: root not >95%; clean `/tmp` prometheus leftovers if critical  

## 6. Disk hygiene

Safe deletes when disk critical:

- `/tmp/prometheus*`, `/tmp/enwik*`, `/tmp/p2m*`, `/tmp/e10*`, old `nix-shell.*`  
- `judge_work/` contents (regenerated by judge)  
- Abandoned `PROMETHEUS-v2-p2-*` worktrees after `git worktree remove`  
- Do **not** delete `data/*.parts`, `.git`, or `enwik9` unless parts reconstruct OK  

## 7. What success looks like

Setup agent exits after smoke checklist green and writes one line to `LOG.md`:

`SETUP | machine ready | SCORE=<from judge> | unrestricted=yes`
